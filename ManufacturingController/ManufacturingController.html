Documentation: Programmable Logic Controller (PLC)

This page documents the ManufacturingController Entity and all its associated properties.

ManufacturingController (Entity)

Definition

Industrial control equipment (PLC) responsible for managing the machine.

NGSI Type

Entity Type

id

Definition

Unique identifier for the PLC equipment within the factory network.

Data Type

String

name

Definition

Commercial name, model, or specific designation of the PLC (e.g., S7-1200).

Data Type

String (Property)

brand

Definition

Brand or manufacturer of the PLC equipment (e.g., Siemens, Omron).

Data Type

String (Property)
